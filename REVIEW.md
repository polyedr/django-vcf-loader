# Review: feature/bonus-models

Проверены модели, загрузчик VCF, API, миграция и тесты бонусной ветки.
Обязательная часть задания выполнена. Бонусная схема простая и подходит
для нескольких образцов.

## Что сделано хорошо

- `Species`, `Assembly`, `Chromosome` и `Sample` связаны явно, а координата
  и аллели остаются в `Genotype`. Это не раздувает базу на миллионы лишних строк.
- У справочников есть ограничения уникальности.
- Для фильтра API сохранён индекс `(chromosome, position)`.
- VCF читается построчно, записи пишутся пачками по 5000.
- `GT` берётся по позиции в `FORMAT`, а не всегда из первого поля.
- API отдаёт имена связанных моделей и не делает лишних запросов благодаря
  `select_related`.
- Миграция переносит старые строки на `Homo sapiens`, `GRCh38` и `HG001`.
- Код короткий и читается без дополнительных слоёв.

## Замечания

### 1. Запрос без фильтров возвращает всю таблицу

`GenotypeListView` не ограничивает число строк. После загрузки полного GIAB
это около 3,89 млн записей. Такой ответ может занять память сервера и браузера.

Для тестового задания это допустимо: пагинация не требовалась. Для ручной
проверки полного файла лучше всегда передавать `chromosome` и `coordinate`.

### 2. Повторная загрузка создаёт дубли

У `Genotype` нет уникальности по образцу, хромосоме и позиции. Второй запуск
`load_vcf` для того же файла добавляет такие же строки ещё раз.

Для задания это приемлемо, но проверяющему стоит загружать файл в чистую базу.

### 3. Ошибка в середине файла оставляет часть данных

Успешные пачки сохраняются сразу. Если строка ниже окажется некорректной,
предыдущие записи останутся в базе, а команда завершится с ошибкой.

Для учебного проекта это нормально. Надёжнее было бы выполнять загрузку одного
файла в одной транзакции либо удалять незавершённый импорт при ошибке.

### 4. Импортируется только первый образец

Даже если в VCF несколько sample-колонок, команда читает первую либо имя из
`--sample`. Это соответствует текущей простой модели, но многообразцовый VCF
полностью не загружается.

### 5. Фильтр хромосомы не учитывает сборку

`chromosome=chr1` ищет хромосому по имени во всех сборках. При одной сборке
GRCh38 результат правильный. Если позже загрузить вторую сборку с такими же
именами хромосом, фильтр смешает их записи.

## Тесты

Есть 8 тестов: обычный и сжатый VCF, повторное использование справочников,
получение списка, фильтры, пустой результат и некорректная координата.

Не проверены отсутствующий файл, VCF без строки `#CHROM`, битая координата,
неполный `FORMAT` и повторная загрузка того же файла. Для сдачи текущего
объёма этого достаточно.

## Итог

Бонусная ветка соответствует заданию и остаётся понятной. Основные ограничения
касаются повторного импорта и выдачи всей таблицы без фильтров. На проверке
их можно обойти чистой базой и запросом с `chromosome` и `coordinate`.
